## Temuan

### SEDANG

**1. Label opsi kalkulator memakai jargon teknis** *(R-16, DESIGN.md §7 "hindari jargon tanpa penjelasan")*
Target utama situs adalah founder dan UMKM, tetapi label berasal langsung dari tabel PRD §5.5.B: "Interaksi Kaya (Framer Motion)", "Showcase 3D (R3F)", "Database Cloud (Turso + CRUD)", "Multi-role Auth + Export Laporan", "Payment Gateway (Midtrans/Xendit)". Label yang sama ikut ke pesan WhatsApp dan Telegram.
Usul: label berbahasa awam, nama teknologi pindah ke catatan kecil di kartu, mis.:

| Sekarang | Usulan label | Catatan kecil |
| :-- | :-- | :-- |
| Interaksi Kaya (Framer Motion) | Animasi interaktif | Framer Motion |
| Showcase 3D (R3F) | Tampilan 3D interaktif | WebGL |
| Database Cloud (Turso + CRUD) | Data tersimpan online | tambah, ubah, hapus data |
| Multi-role Auth + Export Laporan | Login per peran + ekspor laporan | sudah termasuk database |
| Payment Gateway (Midtrans/Xendit) | Pembayaran online | Midtrans / Xendit |

Harga dan logika tidak berubah; PRD §5.5.B diperbarui mengikuti.

### RENDAH

**2. Fitur ketiga di setiap baris paket identik** *(R-14)*
Ketiga paket sama-sama menampilkan "Bersih & Minimalis", sehingga baris itu tidak membantu membedakan paket. Usul: tampilkan dua fitur pembeda saja (tipe solusi + backend).

**3. Ikon tombol WhatsApp memakai ikon chat generik** *(R-04)*
DESIGN.md §6.6 menyebut "ikon WhatsApp". Yang terpasang adalah ikon chat lucide; labelnya sudah menyebut WhatsApp, jadi tujuannya tetap jelas. Usul: pertahankan ikon generik (tanpa aset merek pihak ketiga).
